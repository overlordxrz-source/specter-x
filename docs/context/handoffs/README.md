# Branch handoffs

Use one file per active feature branch, named after the branch with `/` replaced by `-` (for example,
`docs-persistent-context-protocol.md`), or put the same fields in the PR
description. Copy [the branch handoff template](../BRANCH_HANDOFF_TEMPLATE.md).

These files are branch-local coordination artifacts, not evidence and not the
canonical current-state page. The integration/owner process reconciles accepted
facts into `docs/handbook/agent-handoff.md`. Do not overwrite another branch's
handoff or use this directory to promote a capability.
